# Diabetes Prediction ML Model

A machine learning project to predict diabetes using the Pima Indians Diabetes Dataset.

## Models Used
- Logistic Regression
- Decision Tree
- Random Forest

## Libraries
- pandas, numpy, scikit-learn, matplotlib, seaborn

## How to Run
1. Clone this repo
2. Install libraries: pip3 install pandas numpy scikit-learn matplotlib seaborn
3. Run: python3 diabetes_model.py

## Results
Random Forest gave the best accuracy of ~81%
